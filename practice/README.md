# 📝 Practice Logs (student-owned)

One markdown file per practice session.

**File name format:** `YYYY-MM-DD-track-topic.md`
*Example:* `2026-10-09-1A-vowels.md`

**How to add a log:**
1. Copy `practice-log-template.md`
2. Rename it with today's date and the track
3. Fill it in honestly — especially the self-check (✅/🔴 per vowel/sound)
4. Commit and push
5. Tell your tutor: "check my repo"

Your tutor reads every log and replies with feedback, corrections, and quiz questions.
