## What this repo is

My personal Mandarin practice log, run together with my AI tutor.

- **The tutor** pushes: lesson materials, audio, the curriculum, and my progress tracker — and updates them after every session.
- **I (the student)** push: one practice log per session, plus any questions.
- **The tutor** reviews my logs and gives feedback before the next lesson.

This repo is the single source of truth for my progress.

## 📂 Structure

| Path | Owner | What it is |
|------|-------|-----------|
| `TRACKER.md` | Tutor | My live progress tracker (updated after every lesson) |
| `curriculum.md` | Tutor | Full learning roadmap — 6 phases, HSK-aligned |
| `lessons/` | Tutor | Current lesson materials |
| `audio/` | Tutor | Lesson audio (native Mandarin voice) |
| `practice/` | **Me** | My practice logs — one file per session |

## 🔁 How a session works

1. I practice using the current lesson + audio (shadow track, recording, self-check).
2. I copy `practice/practice-log-template.md` → `practice/YYYY-MM-DD-track-topic.md`, fill it in, commit, push.
3. I tell my tutor: **"check my repo."**
4. The tutor reviews my log, gives feedback + a mini-quiz, and pushes an updated `TRACKER.md`.
5. If the checkpoint passes, the next track unlocks.
